Sign-in and two-step verification — native

Spec: screens/sign-in.md · Blueprint S1, S11, S12. These screens are built in SwiftUI; this page approximates them with the mobile CSS to show layout, order and copy. No tab bar before sign-in.

The second step is a code by email or from an authenticator app. The demo company never shows a code step and never sends an email. Add ?dark=1 for dark mode.

  1. No tab bar, no camera prompt until "Scan badge" is tapped. A Bluetooth scan on this screen is a badge.
  2. A badge that belongs to an admin, manager or cs is answered with "This account signs in with a password."
  3. Privacy and Terms open in an in-app browser sheet without signing in (K1).
  4. Errors appear under "Sign in": wrong password, too many tries, can't reach LiveOpsHub.
  5. No "create account", no prices, no "forgot password" in 1.0.
  1. The person chooses: Email or Authenticator app. Email is offered to every role that uses two-step, admin included. Choosing the segment sends nothing; "Send code" does.
  2. "Send again" shows its wait; when the limit is reached it is replaced by a sentence that says what else works.
  3. The "check your spam folder" hint appears 20 s after a send if nothing was typed.
  4. Wrong code: field clears, "That code isn't right." Expired: "That code has expired. Send a new one." After 5 minutes: back to Sign-in.
  5. No email on file: the Email segment is not shown; a footnote says it can be added in Account.
  6. Demo company: this screen never appears.
  1. Until set-up is finished the account can only open Account, sign out, or delete the account. No tabs.
  2. Drawn with the method choice on the same screen; the spec allows a "Set up now" button first — ios-engineer's call.
  3. Workers and hosts never see this in 1.0.
  1. Two steps of one flow shown together: enter the address → "Send code" → type the code.
  2. An address counts only after its code was confirmed. If one is already on file, the screen offers to confirm that one.
  3. Next: recovery codes, shown once, with "I've saved these codes".
  4. Demo company: set-up cannot be opened; the Account row reads "Not available in the demo company."
