# Code Audit — getwhatnot.com / LiveOpsHub (packing-station)

_Reviewed 2026-10-27 · commit `63181d1` (main) · app.py 15,834 lines / 344 routes · templates.py 12,986 lines_
_Method: 7 parallel reviewers by area + cross-cutting review; every Critical/High item below was re-checked against the code by hand._

## Bottom line

- **Foundations are solid.** Per-tenant SQLite files (`/data/orgs/<org>/`) give real data isolation; bcrypt, CSRF, CSP, parameterized SQL, `_flock` / `update_json` helpers are all well built. All 216 API calls in templates.py resolve to real routes. All 63 inline script blocks parse.
- **The real risk is state consistency, not hacking.** Several code paths (CSV import, TikTok sweep, regroup, revert, cancel, backfill, pack upload) each change `status`, cancellations and stock depletion with their own rules. Some of them undo warehouse work or deduct stock twice.
- **Three things are live operational bugs today:** the TikTok sweep resets picked/flagged orders to pending, regroup wipes packed progress, and the webhook accepts unsigned requests.

## 🟡 P2 — hygiene

- **Broken routes:** `/api/cleanup` always 500 (`cleanup_old_files()` missing org, 12257); `/api/orgs/create` decorators sit on `_create_tenant` (11327); bestsellers always empty (`'sale (%'` never written, 7287).
- **4 gunicorn workers:** `_tt_last_event` per-process → fast live polling triggers ~25% of the time; `pdb_init()` ALTERs unlocked at import (deploy can crash a worker); boot seeders duplicate rows; USPS tracking loop unguarded and first run waits 6h (backups may never run with frequent deploys).
- **Timeouts:** TikTok refresh loops, multi-box rates, Anthropic client (default ~10 min) can exceed the 300s worker timeout.
- **Time zones:** TikTok epochs converted with server clock (UTC) → lives crossing midnight UTC split into two shows.
- **Sensitive data at rest:** SSN / bank / temp passwords in plaintext JSON; backups unencrypted in main R2 bucket; TikTok tokens plaintext.
- **Hire links never expire** and return the full hire row incl. I-9 data.
- `/api/repair-videos` lets a tenant admin list/rewrite every tenant's R2 objects (prefix not forced).
- 17 unused routes (debug/maintenance ones should be superadmin-only or deleted). `"picker"` used in `req_role` but not in `VALID_ROLES`.
- Connection hygiene: 285 `pdb()/sdb()` opens, 9 functions use `finally`. Add `with closing(sdb()) as c, c:`.

## Recommended order

1. P0 #1–#3 (TikTok) — one small PR, staging first, then main.
2. P0 #4 (labels) + #6–#8 (escalation/XSS).
3. One shared **status state machine** (`set_status(c, sid, new, actor)`) used by every path, plus one depletion rule. This removes most of P1.
4. `busy_timeout` in `sdb/gdb/pdb`, DB-backed live signal, locks on boot code.
5. Module split (already on the roadmap) — do it after the state machine, not before.
